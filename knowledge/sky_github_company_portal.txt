== GitHub ו-Company Portal בסביבת SKY ==

--- GitHub SKY – Enterprise עצמאי (sky320) ---
כל הפיתוח של SKY עבר ל-Enterprise נפרד משלו ב-GitHub (enterprise name: sky320), מופרד מה-Enterprise הקודם.
שמות הארגונים השתנו:
- sky320-developers ← השם הישן ← כיום: sky320-org
- MCS-LZ-SAFE ← השם הישן ← כיום: AWS-PLAT-LZ-SAFE

הארגונים הישנים (עם השמות הישנים) הפכו לקריאה בלבד מרגע המעבר, ולאחר כחודש נחסמה אליהם הגישה לגמרי.
כל ה-repos, האדמינים, ה-GitHub teams, ההרשאות וה-GitHub projects הועתקו לארגון החדש.
לא הועתקו אוטומטית: repo secrets & variables, GitHub apps וכדומה — אלה צריך להגדיר מחדש בארגון החדש.
אם יש אוטומציה שמשתמשת בשם הארגון הישן — יש לעדכן אותה לשם החדש.

https://github.com/orgs/sky320-org/sso
